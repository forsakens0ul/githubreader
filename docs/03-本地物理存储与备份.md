# 本地物理存储与备份同步

GitHub Reader 尊重你的数据主权，所有阅读数据、书架配置与书籍缓存完全保留在用户本地环境。

## 1. 浏览器 IndexedDB 存储
- 默认采用浏览器标准的 IndexedDB 技术持久化。
- 即使关闭浏览器或断网，已读章节均可离线瞬间打开。
- 零后端依赖，无需注册账号，保护用户阅读隐私。

## 2. 绑定本地物理硬盘文件夹 (File System Access API)
- 支持通过 W3C File System Access API 绑定本地任意磁盘目录（如 `D:\Books\GitReader`）。
- 一键同步：将 IndexedDB 中缓存的仓库内容，以结构化目录形式导出为真实的 `.txt` / `.md` 文件树写入硬盘。
- 方便配合本地文本编辑器、Obsidian、Logseq 或电子书管理工具（如 Calibre）进一步利用。

## 3. 全量数据导入与导出
- **导出备份**：一键生成全量 JSON 备份包（包含书架列表、阅读进度、划线批注、个性化设置）。
- **导入恢复**：在任何新设备或新浏览器上一键导入还原，无缝衔接阅读进度。
