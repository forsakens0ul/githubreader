# 技术架构与自建部署

GitHub Reader 采用现代化纯前端静态架构，无需运维后端服务器或数据库，部署极其轻量。

## 核心技术栈
- **核心框架**：React 18 + TypeScript + Vite 5
- **样式与组件**：Tailwind CSS + Radix UI + Lucide Icons
- **本地数据库**：Dexie.js (IndexedDB 包装层)
- **排版引擎**：Coreader 阅读引擎深度融合与中文段落流式分页
- **本地文件读写**：W3C File System Access API
- **全文检索**：MiniSearch 轻量级全文索引

## 自建部署

### 1. 部署到 Vercel
1. Fork 或 Push 本仓库到你的 GitHub。
2. 登录 [Vercel](https://vercel.com/)，选择 **Add New Project** 并关联仓库。
3. 构建配置：
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. 点击 **Deploy** 即可一键上线。

### 2. 部署到 Cloudflare Pages
1. 在 Cloudflare 控制台选择 **Workers & Pages** -> **Create application** -> **Pages**。
2. 连接 GitHub 仓库并选择 `githubreader`。
3. 预设选择 `Vite`，点击保存并部署。
