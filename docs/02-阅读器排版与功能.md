# 阅读器排版与核心功能

GitHub Reader 深度集成了 Coreader 专业排版引擎，提供了丰富的阅读增强能力。

## 1. 智能排版与分页
- **段落级排版**：保留完整段落结构，中文首行缩进（2em），两端对齐，彻底告别字符生硬折行。
- **字符偏移锚定**：阅读进度以原文字符偏移为锚点，无论如何缩放窗口、更改字号或行距，重新分页后始终停留在当前正在阅读的段落。
- **双阅读模式**：支持经典「分页模式」与「连续滚动模式」，随时一键切换。

## 2. 个性化主题与字号
- 提供四套精心调校的阅读配色：**羊皮复古 (Sepia)**、**护眼绿 (Eye-Care)**、**象牙白 (Light)** 与 **极夜黑 (Dark)**。
- 自由调节字号（12px ~ 32px）、行间距与页边距。

## 3. 划线、笔记与语音朗读
- **划线高亮**：鼠标划选正文段落，即可在弹出菜单中添加多色高亮。
- **读者笔记**：为划线文本添加个人心得与批注，随时可在目录侧边栏中回溯查看。
- **语音朗读 (TTS)**：内置 Web Speech API，支持语音语速、语调调节与段落自动连续播放。
