# 快速上手指南

欢迎使用 **GitHub Reader**！这是一款专为公开 GitHub 文本仓库打造的现代化 Web 电子书阅读器。

## 什么是 GitHub Reader？

GitHub 上有大量高质量的开源书籍、技术教程、随笔专栏与文档合集。然而，直接在网页版 GitHub 上阅读代码仓库体验并不理想：
- 缺乏书籍式的连续翻页排版；
- 每次调整窗口或字号都会迷失当前位置；
- 目录层级复杂，大量非文本文件（如构建脚本、配置等）严重干扰视线；
- 无法做读书笔记、文字高亮或语音朗读。

GitHub Reader 应运而生。它能够智能识别仓库中的 Markdown 与 TXT 文件，将其整理为规整的书籍目录与章节，并提供媲美专业电子书阅读器的沉浸式体验。

## 开始你的第一本书

1. 打开应用主页（书架）。
2. 在输入框粘贴任意公开仓库的链接（例如 `owner/repo`，或具体的 GitHub URL）。
3. 点击 **「开始解析」**。
4. 解析完成后，封面卡片将立即加入你的本地书架，点击即可开启翻页阅读！
